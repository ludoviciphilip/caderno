# Security Policy

Caderno is a local-only, offline note-taking app (no network access, no accounts), so the attack surface is small
— but if you find a security issue (e.g. in file/path handling, PDF export, or image import), please report it
privately rather than opening a public issue.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository:
https://github.com/ludoviciphilip/caderno/security/advisories/new

You can expect an initial response within a few days. Please include:

- the version/commit you tested
- your distro, GTK and libadwaita versions
- steps to reproduce

## Supported versions

Caderno doesn't yet have tagged releases; please report issues against the latest `main`.
